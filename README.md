# 假勤管理與行事曆 (Attendance Planner)

> 專為個人與團隊打造的高質感假勤、特休、病假與遠距辦公 (WFH) 規劃儀表板，支援 2026～2027 台灣國定假日智慧判定與連假攻略試算。

## ✨ 核心功能亮點

1. **莫蘭迪優雅視覺風格 (Morandi Palette)**
   - 低飽和度、溫潤護眼配色，呈現沉穩雅致的高質感介面。
   - 滿版響應式設計（Full-width），自適應視窗縮放大小。

2. **左右對照看板模式**
   - **左側**：月曆行事曆（完整標記 2026/2027 台灣國定假日、週末及個人休假）。
   - **右側**：假勤排程清單（具備平滑滾動條、即時完成勾選狀態、過期假勤自動過濾）。

3. **智慧假勤額度連動**
   - **特休 (年假) 額度**：支援小時／天數即時切換、到期舊假合併與剩餘天數精算。
   - **全薪病假**：清晰掌控健康儲備天數。
   - **遠距辦公 (WFH)**：隨行事曆檢視月份動態計算當月額度、已排天數與年度累計上限。

4. **國定假日自動排除與請假試算**
   - 排假區間自動扣除週休二日與國定放假日，精準計算實際需扣除的工作日時數。
   - 提供「🧮 假期試算 & 連假請假攻略」模擬器，快速試算請假效益最大化。
   - 支援匯出高清假勤資產結算圖卡 (PNG)。

5. **純前端安全架構**
   - 100% 純前端靜態網頁（HTML5 + Vanilla JavaScript + CSS3）。
   - 資料自動儲存於使用者的瀏覽器 `localStorage`，兼顧隱私與離線可用性。

直接在瀏覽器開啟 `index.html` 或 `work_life_planner.html` 即可使用，無需安裝任何伺服器或後端相依套件。
